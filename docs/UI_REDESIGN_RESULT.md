# VANTAGE UI 개편 결과

2026-09-24 Raspberry Pi 5 / Ubuntu ARM64 배포 기준.

## 적용 내용

| 요청 | 적용 결과 |
|---|---|
| 서비스 이름 | VANTAGE. `app/branding.py`에서 이름을 관리하고 헤더·푸터·제목·인기 메뉴에 적용 |
| 모바일 탐색 | 종목명·현재가·등락률과 거래대금·거래량을 나누어 배치. 별 버튼으로 관심등록. 가로로 넘길 수 있는 시장/순위 메뉴 |
| 관리자 진단 | 탐색 시세시각·공급자 상태는 서버 권한 검사 후 관리자에게만 반환. 모바일은 접힌 진단 영역 |
| 상세 가격 | 현재가와 전일 대비 금액·등락률을 분리. 모든 손익은 상승 빨강·하락 파랑 |
| 표시 통화 | 거래 통화/KRW/USD 선택을 탐색·상세·차트·주문 참고 금액·계좌·랭킹·관심종목에 공유. 실제 결제 통화와 금액은 별도 명시 |
| 차트 | 6개 기간 모두 첫 종가→마지막 종가, 변화 금액/비율, 실제 제공 날짜 범위 표시. 마우스·터치·키보드 시점 이동. 실패 시 재시도 버튼 |
| 시장가 주문 | 신규 지정가 UI/생성 API 제거. 이전 주문 기록과 취소 API는 보존 |
| 수량 비율 | 최대/50/25/10/5%. 서버 Decimal 계산, 정수 주 내림, 0주 주문 차단. 매수는 수수료 포함 구매 가능량, 매도는 보유 수량 기준 |
| 랭킹 | 화면 활성 시 10초 조회, 서버 캐시 공유. 마감 시 마지막 순위 유지. 조회 장애 시 마지막 정상 결과/시각 표시. 관리자 제외 |
| 관심종목 | 종목명·현재가·등락 금액·등락률을 카드 안에서 분리. 개별 오류 표시 |

공개 종목 식별자 `symbol`은 상세 이동·주문·관심등록에 필요해 API에 유지합니다. 일반 사용자 탐색 화면에는 코드 열을 표시하지 않습니다. 공급자 진단 필드는 탐색 API에서 서버가 제거합니다.

## 변경 파일

- `app/branding.py`: 브랜드 상수
- `app/main.py`: HTML 브랜드 주입, 랭킹 10초 경계, 마지막 정상 결과 유지, 관리자 캐시 제외
- `app/routes.py`: 탐색 진단 권한·관심등록 상태, 비율 주문 견적, 신규 지정가 생성 API 제거
- `app/trading.py`: 서버 수량 비율/주문 가능 여부 계산
- `app/static/index.html`, `app/static/app.js`, `app/static/portal.js`, `app/static/style.css`: 화면·표시 통화·차트·주문·모바일 개편
- `tests/test_service.py`, `tests/test_expansion.py`, `tests/browser_server.py`, `tests/browser_smoke.py`: 회귀·권한·비율·브라우저 검증
- `README.md`, `docs/UI_REDESIGN_REQUEST.md`, 이 문서

## 데이터와 설정

이번 UI 작업에서 새 DB migration이나 환경변수·API 키를 추가하지 않았습니다. 실행 중이던 이전 이미지의 스키마는 v2/v3였으며, 이미 저장소에 있던 v4/v5 운영 기능 migration이 이번 배포 때 적용됐습니다.

운영 DB를 비공개 `backups/`에 먼저 백업하고 별도 DB에 복원했습니다. migration을 두 번 실행한 뒤 **13개 기존 테이블의 모든 기존 컬럼 값**을 비교해 동일함을 확인했습니다. 계정 3개, 지갑 6개, 거래 4건, 보유 종목 3건, 환전 2건과 기존 주문/관심종목 기록을 보존했습니다. 운영 계정을 초기화하지 않았습니다.

기존 지정가 주문은 임의 삭제/취소하지 않습니다. 새 주문 생성만 막고, 이미 등록된 주문은 기존 조건으로 처리하며 본인이 조회·취소할 수 있습니다.

## 검증

- PostgreSQL 통합 테스트: **56개 통과**. 인증·지갑·환전·동시 거래·소유권·관리자·이체·랭킹과 새 비율 계산 검증 포함
- Chromium: 데스크톱 1440px 및 모바일 390px에서 가입, 환전, 탐색, 전역 통화, 차트 6개 기간, 매수/매도 수량, 0주 차단, 관심종목, 공개 계좌, 10초 랭킹 확인
- 랭킹 API 장애를 주입해 기존 순위 유지 확인
- 관리자 모바일 진단, 일반 사용자 진단 필드 차단, 관리자 랭킹 제외 확인
- 브라우저 JavaScript 오류 없음, 모바일 페이지 가로 넘침 없음
- JavaScript 문법, Python 컴파일, Git diff 공백 검사 통과
- 실제 ARM64 Docker Compose build/up 완료. 운영 컨테이너 전체 healthy
- 실제 TLS 인증서 검증을 켠 HTTPS `/health` 응답 정상. HTTP는 HTTPS로 308 redirect
- `.env`, API 키, DB 백업, 인증서, 브라우저 테스트 산출물의 Git 제외 확인 및 공개 파일 비밀정보 검사 통과

브라우저와 통합 테스트의 가격/환율은 격리된 테스트 대역입니다. 이 결과가 공급자 계약상 모든 종목·기간 데이터의 제공을 보장하지는 않습니다.

## 접속과 사용

[운영 사이트](https://mockinvest.duckdns.org/)에서 새로고침하면 적용된 화면을 볼 수 있습니다. CSS/JS URL 버전을 갱신했습니다. 과거 화면이 계속 보이면 강력 새로고침을 사용하세요.

전역 표시 통화는 브라우저에 저장되며 이전 저장 키도 이어 읽습니다. 통화 선택은 금액 표시만 바꿉니다. 랭킹 수익률의 기준은 기존 KRW 회계 기준으로 유지합니다.

## 남는 공급자 제약

- 랭킹 화면 10초 갱신은 실제 시세가 10초마다 바뀐다는 뜻이 아닙니다. 가격·차트·순위는 각 공급자의 캐시·갱신 주기·시장 시간·이용 권한에 따릅니다.
- 환율은 기존 ECB 일별 기준환율입니다. 차트 통화 변환은 현재 기준환율을 전체 구간에 적용합니다.
- 차트는 실제 제공 구간을 표시하며 누락된 과거 가격을 만들지 않습니다.
- 거래 결제는 USD/KRW 원래 통화로 수행하고 서버에서 다시 검증합니다. 실제 증권사 주문·실제 자금 이체는 없습니다.
