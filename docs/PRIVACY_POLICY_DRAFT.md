## 현재 구현에 근거한 내용

- 계정 인증: 아이디와 비밀번호 해시. 비밀번호 원문은 DB에 저장하지 않는다.
- 서비스 제공: 모의 주문·거래·가상 지갑·관심종목·성과 기록.
- 선택 입력: 소개 글과 프로필 이미지. 업로드 이미지는 검증·재인코딩하며 원본 파일명은 저장하지 않는다.
- 운영 관리: 관리자 메모, 관리자 작업 기록, 서비스 요청 로그 등이 있다. 실제 필요성·최소화·보유 근거를 확정해야 한다.
- 회원 공개: 기본 비공개. 회원이 ‘프로필·포트폴리오 공개’를 켜면 다른 로그인 회원에게 아이디, 사진, 소개, 가입 기간, 보유 종목·수량, 가상 잔액·평가액, 손익과 과거 성과를 표시한다.
- 랭킹: 별도 선택. 아이디, 가상 평가액·손익·수익률과 순위를 현재 및 과거·향후 주간 랭킹에 표시한다. 사진·상세 포트폴리오는 프로필 공개 선택에 따른다.
- 공개 목적: 회원 간 모의투자 기록 비교. 두 항목을 거부해도 모의거래는 이용할 수 있다. 공개 해제 후 서버 조회는 비공개 처리되지만 타인이 이미 저장한 화면까지 회수할 수는 없다.
- 공개 선택 변경 기록: 사용자 ID, 공개 항목 선택값, 안내 버전과 변경 시각. 계정 삭제 시 DB에서 함께 삭제한다. 보관 목적은 공개 설정 관리와 변경 내역 확인이며, 적용 법적 근거는 최종 검토한다.
- 회원 탈퇴: 계정 및 주요 개인별 서비스 DB 기록을 삭제한다. 상대방 이체 기록은 삭제하는 대신 계정 연결을 해제한다. 운영 로그·백업까지 즉시 삭제되는 것은 아니므로 별도 확정 정책을 기재해야 한다.
