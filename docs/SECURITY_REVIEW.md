## 수정

- **의존성 취약점:** `pip-audit -r requirements.txt`에서 Pillow, Starlette, pytest의 공개 취약점이 보고되었다. Pillow 12.3.0, Starlette 1.7.0, pytest 9.0.3으로 갱신하고 호환되는 FastAPI 0.141.1을 적용했다. Starlette도 명시적으로 고정했다. 의존성 재검사에서 알려진 취약점이 보고되지 않았고 `pip check`도 통과했다. 이는 검사 시점에 해당 의존성 해석 결과에 대한 결과이며 모든 보안 위험의 부재를 뜻하지 않는다.
- **직접 접속 시 요청 제한 우회:** HTTP 요청과 SSE 연결 제한이 클라이언트가 보낸 `X-Real-IP`를 무조건 신뢰했다. 기본값은 연결 상대 주소만 사용하며, `TRUST_PROXY_HEADERS=true`인 경우에만 유효한 IP 헤더를 신뢰한다. 기본 Compose는 web 포트를 호스트에 공개하지 않고 nginx가 헤더를 덮어쓰는 기존 경계를 유지한다. 이 옵션을 켠 web에 신뢰할 수 없는 직접 접근을 허용해서는 안 된다.
- **검증 오류의 입력 노출:** 기본 입력 검증 오류는 비밀번호 등 제출값을 응답에 포함할 수 있었다. 오류 응답은 `type`, `loc`, `msg`만 반환하도록 변경했다.
- **정지 계정 로그인:** 정지된 계정은 보호 API에서 차단되지만 로그인 단계에서는 세션이 발급됐다. 비밀번호 검증 후 계정 상태도 검사하여 새 로그인 세션 발급을 차단했다.
- 테스트 실행기는 현재 Python 인터프리터를 사용하도록 변경하여 격리 환경의 새 의존성으로 실제 테스트가 실행되게 했다.
